# 简谱编辑器

一个纯前端的简谱（numbered musical notation）编辑器：导入 MIDI 自动转成简谱，
在浏览器里编辑、播放、导出 JSON / MIDI / SVG / PNG / 文本简谱 / 打印。

纯 TypeScript + DOM + Web Audio，无框架、无构建期依赖（用 Vite 只做开发服务器与打包）。

## 在线使用

在浏览器打开 `index.html` 即可（需通过静态服务器访问，`npm run dev` 或 `npm run preview`）。
数据自动保存在浏览器 `localStorage`，刷新不丢。

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
```

## 功能概览

- 导入 `.mid`：多轨合并、按小节量化、自动识别拍号与调号、按「调主落在 C4–B4」的窗口给八度点
- 导入 / 导出简谱文本（见下方语法），适合从聊天软件粘贴旋律
- 编辑：点击选区 + 键盘输入，插入 / 覆盖两种模式，撤销重做，自动保存
- 记号：附点、连音线（tie）、圆滑线（slur）、三连音、休止符、增时线、减时线、八度点、歌词
- 一键精简记号：小节内同音连音线链合并成「数字 + 增时线」（四分 / 二分 / 全音符），小节内连续休止符合并成更少的休止符；跨小节长音保留
- 全曲移调：以**半音**为单位升任意度，默认只平移调号（`1=C → 1=D`，谱面数字不动），也可改成改写音符（调号不变，谱面出现 `#` `b` 与八度点）
- 排版：自动按小节分行，谱面按 `1 2 3 4 5 6 7 0 - = =` 的简谱习惯绘制
- 播放：Web Audio 合成，可调速度、循环、乐器音色，跟随播放高亮
- 导出：JSON 工程文件、MIDI、SVG / PNG 图片、文本简谱（侧栏复制）、打印（浏览器可存成 PDF）

## 简谱文本语法

用于侧栏「简谱文本」的「导入文本 / 导出到文本框」：记号之间用空格分隔，`|` 切分小节（换行等价于空格）。
整段不写 `|` 时，程序按当前拍号自动切分小节。

| 写法 | 含义 |
| --- | --- |
| `1 2 3` | 音级（首调唱名），`0` 休止符 |
| `00` `0000` | 二分休止（2 拍）/ 全休止（4 拍） |
| `5.` | 附点（只支持一个附点） |
| `5/` `5//` `5///` | 时值缩短一级：八分 / 十六分 / 三十二分 |
| `5 -` `5 - -` | 增时线（每根延长一拍） |
| `5'` `5''` | 高八度（撇号在上，可叠加两个） |
| `5,` `5,,` | 低八度（逗号在下，可叠加两个） |
| `#5` `b5` | 升号 / 降号（写在数字**前面**） |
| `|` | 小节线 |
| `\|:` `:\|` | 反复开始 / 反复结束线 |

示例：

```
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 -
1./ 1./ 2 3 | 4 4 3 - |
```

导出文本时满两拍以上的音写作「数字 + 增时线」（3 拍 = `5 - -`），二分 / 全休止写成 `00` / `0000`，
这两种写法导入时也都读得回来。调号、拍号、速度、标题等乐曲信息**不在文本里**，
用侧栏「乐曲信息」改；三连音、圆滑线、歌词同样不在文本格式内。

## 快捷键

数字 `1`–`7` 输入首调音级，`0` 休止符，`-` 增时线，`Enter` 在小节末尾追加一个四分音符，
`Q W R T Y U` 时值（全 / 二分 / 四分 / 八分 / 十六分 / 三十二分），`D` 附点，
`S` / `F` / `N` 升号 / 降号 / 还原，`]` / `[` 高八度点 / 低八度点，`L` 三连音，
`V` 连音线，`B` 圆滑线，`Delete` / `Backspace` 删除，`Insert` 切换插入 / 覆盖，`E` 打开微型编辑浮层，
`← →` 移动光标，`↑ ↓` 在小节之间移动光标，
`Alt + T` 全曲精简记号（合并小节内同音连音线链、小节内连续休止符），
`Ctrl+Shift+] / [` 全曲升高 / 降低 1 个半音（只平移调号），`Ctrl+Shift+M` 打开「全曲移调」对话框，
`Ctrl+Shift+= / -` 放大 / 缩小谱面字号，`Space` 播放 / 暂停，`Esc` 停止播放并回到开头，
`Ctrl + O` 导入 MIDI，`Ctrl + S` 保存 JSON。
完整快捷键见应用内「快捷键」对话框（顶栏「快捷键」按钮）。

## MIDI 导入说明

- 取所有轨的最高声部旋律线（多轨会合并成一条旋律），鼓组轨（MIDI 通道 10）忽略；
- 调号取导入对话框里选定的调，默认 `C`；八度点按「调主落在 `C4–B4`」这个窗口给，
  与播放 / 导出 MIDI / 全曲移调用的是同一个基准，所以听到的和导出去的音高与源 MIDI 逐音一致。
  旋律整体坐在窗口之下的歌（男声低八度录音）谱面会多出一批低音点，可换调或用 `]` / `[` 逐个改；
- 默认量化到十六分网格，可按谱面需要改成三十二分 / 八分 / 四分网格；
- 间隙处理（导入对话框，默认「合并 < 1/16 拍」）：音符之间**小于**阈值的缝隙并入前一个音符、不写休止符，
  不小于阈值的缝隙保留成休止符。阈值以四分音符 = 1 拍计，可选 `0`（保留所有间隙）/ `0.25` / `0.5` / `1`；
  缝隙先按量化网格吸附，所以阈值要 ≥ 所选网格才起作用（网格 1/8 + 阈值 1/16 等于没开）；
  连续的小缝会链式并进同一个音，前一个音因此变长（多出增时线，跨小节时产生连音线），
  落在被合并缝隙上的歌词音节会挂到该音上。留缝明显的录音选 `0.5` 或 `1`，需要休止位置精确就选 `0`。

- 导入后自动做一次「记号精简」：小节内同音连音线链合并成「数字 + 增时线」，小节内连续休止符合并成更少的休止符，跨小节长音保留。
- 文件里带歌词（SMF 歌词事件 `0x05`）时一并导入：音节按 tick 落在对应音符的**开头**，
  长音上的多个音节连写拼接，前奏 / 间奏落在休止上的音节与纯连字符（`-` `_`）不占音符；
  中文歌词的 UTF-8 与 GBK 编码都能识别；导入后自动打开「显示歌词」，导出 MIDI 时歌词写回原位置。


## 关于连音线与休止符

- 连音线（tie）只在**同音高**音符之间合并时值；跨小节的长音保留成跨小节连音线，小节内不跨拍号切分；
- 圆滑线（slur）是独立的分句弧线，连续标记三个以上音符时共用一条弧线，不会被连音线改写；
- 「简⌒」按钮 / `Alt + T` 把小节内同音连音线链合并成更长时值：
  2 拍 → 二分音符，3 拍 → 四分音符 + 两条增时线，4 拍 → 全音符，6 拍 → 二分音符 + 两条增时线；
- 时值拼写取**最优解**（动态规划）：在能精确表示该拍数的所有写法里选「连音线最少、其次记号最少」，
  代价相同时长时值写在前面。例如 3.75 拍给「四分 + 两条增时线 + 附点八分」（1 条连音线），
  而不是贪心的「附点四分 + 两条增时线 + 十六分」（3 条连音线）；
- 只在「时值能精确表示、合并后连音线确实变少」时才改写，所以可以反复点（幂等）；
  链首的歌词、跨小节连音线保留，力度取链上最大值。
- 受简谱记法限制：增时线最多三条（再长要换全音符），附点音符后不接增时线，
  所以超过全音符的长音（如 5 拍）仍需保留连音线；三连音链、带歌词的链、跨小节链不动。
- 剩下的连音线一般是 2.5 拍、3.5 拍这类「附点音符 + 连音音符」和跨小节长音——在现有记法下已是最省连音线的写法。
- 连续休止符同样会被合并成更少的休止符：`0:4. 0:4. 0:4`（三个，4 拍）→ 一个全休止 `0:1`，
  `0:4. 0:8`（2 拍）→ 一个二分休止 `0:2`，`0:8 0:8` → 一个四分休止。
  休止符**不能用增时线延长**（增时线只延长音符），所以拼写只用纯时值，
  并且只在「休止符个数确实减少」时才改写（同样幂等）；跨小节的休止不合并，音符会打断休止段。
- 合并效果的可复现回归见 `tests/tie-compact.test.ts`、`tests/rest-compact.test.ts`
  （合成谱面 + 逐小节核对拍数守恒：合并前后 `barBeatLength` 不变）。

## 关于全曲移调

「全曲移调」以**半音**为单位（工具栏「全↑ / 全↓」走 1 个半音，`Ctrl+Shift+M` 的对话框可选 ±24 个半音），
一次操作全部可撤销。对话框里有两种写法，听到的音高变化相同，谱面不同：

- **改调号**（默认，标准简谱写法）：只把调号平移，`1=C → 1=D`，谱面数字一个都不动；
  播放与 MIDI 导出按新调发声。升降号偏好沿用原调（降号调继续写降号 `1=bG`，升号调继续写升号 `1=D#`），
  C 调按移动方向选（向下 `1=bB`，向上 `1=C#`）。
- **改变音符**：调号不动，逐音符改写成新的「音级 + 升降号 + 八度点」，
  例如 `1=C` 升 2 个半音后 `1 3 5` 写成 `2 #4 6`。适合要把 `#` `b` 留在谱上的场合。

两点限制值得知道：

- 八度点只能点到 ±2 个八度，越界的音符会被压回并给出提示（音高差一个八度）；
  需要更大的幅度就用「改调号」，它不动音符，没有这个限制。
- 调号里只有音名、没有八度，发声时调主一律落在 `C4–B4` 这个窗口，
  所以「降低 5 个半音」把 `1=C` 改成 `1=G` 后，播放会**升高 7 个半音**（差一整个八度）：
  音级关系完全正确，而简谱的八度位置本来就由调号所在八度决定。对话框与提示都会写明实际变化。

移调走出来的调（`1=C#`、`1=bG` 这类偏门调）在「乐曲信息」的「调」下拉里都选得回来——
该下拉收录 17 个调：15 个常用调，加上移调走得到的 `C#` `G#` `D#` `A#` `bG`。

逐音的八度点（`↑` / `↓` / `○`，快捷键 `]` / `[`）与全曲移调是两回事，前者只改选中音符。

## 目录结构

- `src/core/` 数据模型、光标、历史、排版、渲染、时值拼写、连音线合并、休止符合并、全曲移调、文本简谱
- `src/midi/` SMF 解析、量化、MIDI 导出
- `src/io/` JSON 工程文件读写、PNG 导出、下载与 localStorage 自动保存
- `src/audio/` Web Audio 播放器
- `src/ui/` 谱面视图、工具栏、侧栏、导入 / 帮助对话框、快捷键、编辑交互
- `src/styles.css` 界面与打印样式（`@media print`）
- `scripts/` 辅助脚本（`clean.mjs` 清理生成物、`make-sample-midi.mjs` 生成测试用的 `samples/twinkle.mid`）
- `docs/DESIGN.md` 设计文档
- `tests/` Vitest 单元测试：440 个用例，纯逻辑 + happy-dom 两套环境；只读仓库内的
  `samples/twinkle.mid`，不依赖仓库外的任何文件（克隆下来 `npm ci && npm test` 就是绿的）
- `.github/workflows/` CI 与 GitHub Pages 部署

## 已知限制

- 只支持单声部旋律 + 歌词，不做多声部 / 和弦 / 伴奏谱；
- 没有 MusicXML 导入 / 导出：工程文件用 JSON，与打谱软件交换走 MIDI，纯文本用简谱文本格式；
- 三连音以外的混合复杂节奏（如五连音）不参与量化；
- 长音最长到全音符 + 三条增时线，更长的音仍需连音线；
- 打印走浏览器打印，样式由 `src/styles.css` 里的 `@media print` 控制。
